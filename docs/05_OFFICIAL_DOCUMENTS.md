# KSPDOWA OFFICIAL DOCUMENTS
## Source Register v1.0

## 1. Recognition Order
File supplied to the project:
`KSPDOWA Recognised Order.pdf`

The uploaded file is a two-page scanned document. The parsed text layer is unavailable, so exact order metadata and legal wording must be transcribed from the scanned pages before publishing.

The document must be treated as an official source document and must not be paraphrased into stronger legal claims than the document itself supports.

## 2. Recognition page requirements
Display:
- Document title
- Exact order number
- Exact order date
- Issuing authority
- Exact subject
- Relevant rule/reference
- Original scanned PDF
- View/download controls
- Upload/source metadata

## 3. Future official documents
Add only verified association/government documents:
- Registration certificate
- Recognition orders
- Constitution
- Bye-laws
- Amendments
- Government correspondence
- Annual reports
- Audit reports
- Official proceedings

## 4. Evidence rule
Do not claim that the association is the "only" recognized association unless an authoritative document/source explicitly establishes that fact.

## 5. Document security
Public official documents may be public where approved. Internal association documents must use authenticated access.
