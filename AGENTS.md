# Agent Guidelines & Execution Rules

## Autonomous Task Execution
- **Do not wait for user confirmation for regular tasks**: For standard feature implementations, bug fixes, refactoring, validations, and routine tasks, proceed autonomously and complete the work end-to-end.
- **Complete the entire workflow**: Plan, implement, test, verify, and finalize without stopping for intermediate confirmation.
- **When to stop/ask**: Only pause to ask the user if there is a fundamental requirement ambiguity, missing external credentials, or an irreversible destructive operation that cannot be safely undone.
